# 美股研究总纲（v0，2026-09-28）

## 目标与约束

- 目标：先保本，再尽量提高收益。
- 风险上限：任意滚动 12 个月亏损 ≤ 本金 25%；最大回撤只报告。
- 只做研究与纸面验证；不接券商、不下单。
