# 运行策略 vt_only 的实盘成本与税：1 万美元回放（2026-10-12）

目的：10/30 首批实盘前，算清 vt_only（100% sp500_trend_voltarget，SPY/SSO/BIL）在 1 万美元、整股、
按清单次日收盘成交时，模型收益被哪些因素吃掉多少。不是新研究（不改策略、不计入试验登记）。
脚本：`tools/live_cost_replay.py`（数据为本地库雅虎日线，2008-04-01 至 2026-10-07，18.5 年）。
ETF 的管理费（SSO 约 0.9%/年）与 SSO 的融资成本已含在 ETF 价格里，模型收益已扣除，不再单列。

| 情形（1 万美元） | 年化 | 与上一行差 |
|---|---:|---:|
| 模型（零成本复制组合） | 13.62% | |
| 整股、零成本、无税、无缓冲 | 13.59% | −0.03% |
| + 1% 现金缓冲（实盘与模拟盘设置） | 13.48% | −0.11% |
| + 每笔 5 bp 滑点（相对收盘价） | 12.71% | **−0.77%** |
| + 股息预提 10%（W-8BEN 后，中美协定税率） | 12.61% | −0.10% |
| 对照：同期持有 SPY（全收益） | 11.86% | |

- 每年约 15 个下单日、31 笔订单。**滑点是最大的成本**：每 1 bp 约 0.15%/年。10 bp 时年化 11.86%，与持有 SPY 持平；
  1 bp 时 13.23%，2 bp 时 13.09%。
- 没交 W-8BEN（预提 30%）：12.42%，比交了少约 0.2%/年。
- 现金缓冲把“买不起”从每年约 8 次降到约 1 次，代价约 0.1%/年。

## 中国税务居民的个人所得税（示意，非税务意见）

按现行规定，中国税务居民境外股票买卖所得按“财产转让所得”20% 征税，同一年度内盈亏可以相抵，但不能跨年结转，
次年申报；股息按 20%，在美国已预提的 10% 可抵免。CRS 信息交换下，2025 年多地税务局已公布追缴案例。

粗略估计（假设每年的收益在当年实现并按 20% 纳税；本策略换手高，接近这一假设）：

| | 税前年化 | 税后年化（示意） |
|---|---:|---:|
| vt_only，5 bp 滑点 | 12.61% | 9.52% |
| vt_only，1 bp 滑点 | 13.23% | 10.06% |
| 持有 SPY 18.5 年后一次卖出（股息合计按 20%） | 11.86% | 10.44% |

如果照章纳税，高换手策略的税负明显高于长期持有：持有 SPY 的收益可以递延到卖出时才纳税，
而策略几乎每年都要为当年收益纳税。在这一假设下，策略税后的优势消失，甚至略低于持有 SPY。

## 结论与建议

1. **执行质量最重要**：尽量用收盘集合竞价单（MOC，或带保护价的 LOC）成交，使成交价贴近模型用的收盘价。
   嘉信需在 App/thinkorswim 里确认是否支持；如不支持，在收盘前几分钟用贴近现价的限价单。
2. **交 W-8BEN**：约 +0.2%/年。
3. **税务**：上表只是示意。是否、如何申报境外所得是用户自己的决定，必要时咨询税务专业人士；
   如果按 20% 逐年纳税，长期持有 SPY 在税后可能更划算，这一点值得在 10/30 前考虑。
4. 本回放从 2008 年开始，包含 2008 年大跌（策略在那时避开了大部分下跌），对策略较有利；1955–2025 的长期检验见
   `docs/results/sp500-trend-voltarget.md`。
