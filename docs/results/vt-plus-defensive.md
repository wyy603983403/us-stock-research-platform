# 已批准策略 + 防守趋势组合（2005-10 至 2025-12，2026-10-04）

预先登记：`research/vt-plus-defensive/study.yml`（提交 3c039a2，先于任何收益计算）。
引擎 `usr-sleeve-mix`；防守部分与组合由独立实现 `verify_mix` 逐月核对（243 个月，最大差 4e-16）；
标普部分沿用 `sp500_trend_voltarget` 引擎（已由 `usr-verify-lt` 验证）。数据指纹 `mix-data-v1:sha256:ed28e85c…`。

## 规则

50% 已批准的标普趋势 + 波动率目标（不改参数）+ 50% 防守组合（TLT、IEF、GLD 各 1/3，各自 200 日均线上方持有、
下方持国库券），每月末恢复 50/50；成本 10 bp。

## 结果（243 个月）

| | 年化 | 波动 | 夏普 | 最大回撤 | 最差滚动 12 月 |
|---|---:|---:|---:|---:|---:|
| **组合（50/50）** | **7.8%** | 9.5% | **0.84** | **−16.8%** | **−13.6%** |
| 单独已批准策略 | 10.6% | 18.4% | 0.64 | −26.8% | −25.6% |
| 防守趋势组合 | 4.0% | 7.6% | 0.55 | −22.2% | −11.1% |
| 防守资产一直持有（不用均线） | 6.2% | 9.8% | 0.66 | −27.3% | −20.1% |
| 标普 500 全收益 | 10.9% | 15.1% | 0.77 | −51.1% | −43.4% |

主检验：组合夏普 − 已批准策略夏普 = +0.20，95% 区间（+0.003，+0.40），为正概率 97.7%。
两部分月收益相关系数 −0.13。Deflated Sharpe 0.996（试验登记共 11 组）。**四项标准全部通过。**

关键年份（组合 / 已批准策略 / 防守 / 标普）：2008 +3.4% / −3.4% / +10.2% / −37.1%；
2013 +23.1% / +57.8% / −5.0% / +32.3%；2020 +14.1% / +16.0% / +9.9% / +18.5%；2022 −13.6% / −22.9% / −3.7% / −18.2%。

敏感性（只报告）：标普部分 70% → 年化 9.1%、最大回撤 −20.5%、夏普差 +0.10；30% → 6.4%、−13.3%、+0.26。

## 结论与注意

- 按预先登记的标准通过：风险收益比显著提高（区间下限勉强为正，+0.003），回撤与最差 12 个月亏损约减半。
- **代价是收益：年化少 2.8 个百分点**（20 年终值 4.6 倍 vs 7.7 倍）。这是“更稳”而非“更赚”的改进。
- 防守部分加均线反而比一直持有收益低（4.0% vs 6.2%）；组合的改善主要来自资产间低相关，而不是防守部分的均线。
  这一点是看到结果后的观察，不能据此改规则（改即新研究）。
- 样本只有 20 年，债券处于长期牛市尾段；2022 年股债同跌时防守部分靠均线只亏 3.7%。
- 区间下限只有 +0.003，算上已有 11 组试验，证据是“刚好过线”，不是压倒性的。
- 晋级需要用户人工审查；未批准前不进入订单演练。
