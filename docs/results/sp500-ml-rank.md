# 标普 500 时点成分股：多维特征 + 机器学习排名（2026-10-08）

预先登记：`research/sp500-ml-rank/study.yml`（526f7c4，在计算任何特征、训练任何模型、计算任何收益之前提交）。
两次修订都在计算任何策略收益之前：ce4de63（用户要求加入宏观：4 个股票层面宏观敏感度 + 5 个市场环境变量，只给机器学习用）；
da2909f（只看输入的冒烟测试发现 FRED 的 ICE BofA 高收益利差只有最近 3 年，改用 BAA10Y）。合同原写“可修订一次”，实际两次，如实记录。

方法：2012–2025 每月末的时点成分股（含退市公司），32 个输入（技术 11、资金 5、基本面 7、宏观敏感度 4、市场环境 5）；
每年 1 月用当时已结束的全部月份（扩展窗口，2012 起）训练 LightGBM（超参数登记时固定，未调参），预测下月收益的截面排名；
2015-01 至 2025-11 共 131 个信号月，买前 30 只等权，次日收盘成交，扣 10 bp。数据：Mac 数据库的副本（价格至 2026-10-07）+ BAA10Y。

验证：独立第二实现逐股逐月重算全部特征（2,143,503 个值，0 个不一致）；用已验证的 `cross_section.run` 按同一预测重放组合，
131 个月最大差异 1e-17。价格覆盖率最低 90.8%，基本面覆盖率最低 98.0%。数据指纹 `ml-panel-v1:sha256:c4d13c46…`。试验总数 14。

## 结果（2015-02 至 2025-12 持有期，扣成本）

| 组合 | 年化 | 波动 | 夏普 | 最大回撤 | 最差滚动 12 月 | 单边月换手 |
|---|---:|---:|---:|---:|---:|---:|
| **机器学习前 30** | **14.6%** | 23.8% | 0.69 | −30.2% | −23.0% | 70% |
| 线性对照前 30（同样特征，按文献方向等权打分） | 9.1% | 16.7% | 0.61 | −37.4% | −34.6% | 43% |
| 同池等权 | 10.8% | 17.3% | 0.68 | −31.2% | −23.0% | — |
| SPY | 13.7% | 15.8% | 0.90 | −23.8% | −19.0% | — |

- **主检验未通过**：相对等权月均超额 +0.39%，95% 区间（−0.23%，+1.01%），为正的概率 88%。
- 机器学习相对线性对照月均 +0.52%（区间 −0.33%，+1.34%）——点估计为正，这一条满足。
- Deflated Sharpe 0.945 < 0.95（未通过，差一点）；最差 12 个月 −23%（≤50%，满足）；覆盖率与独立核对满足。
- 退市 −30% 折价：年化 14.5%，结论不变。

## 收益从哪来（只报告）

逐年（机器学习 / 等权 / SPY）：2015 +5.7% / −2.0% / +1.6%，2016 +27% / +18% / +15%，2017 +11% / +19% / +22%，
2018 −15% / −9% / −5%，2019 +27% / +30% / +32%，**2020 +54% / +10% / +16%，2021 +55% / +32% / +31%**，
2022 −23% / −12% / −19%，2023 +21% / +15% / +26%，2024 +0.1% / +12% / +25%，2025 +25% / +12% / +18%。

- 超额几乎全部来自 2020–2021 两年；其余 9 年里有 5 年跑输等权。
- 特征重要性前五都是市场环境变量（10 年−2 年利差 12%、近 3 月利率变化 10%、市场一年涨幅 10%、VIX 7%、信用利差 7%）。
  这些变量对同月所有股票相同，只能通过“什么环境买什么股”起作用；11 年里只有少数几种环境，这种规律很容易是巧合。
- 持仓特征：平均偏向高贝塔、高波动、较小市值、较弱动量的股票（2020、2022 年最明显）——本质是“风险偏好切换”，
  2020 年反弹押对、2022 年同样的倾向亏得更多。
- 不含宏观的机器学习版本：年化 5.4%，**显著跑输等权**（月均 −0.34%，区间 −0.66%，−0.06%）；只用技术面同样显著跑输。
  只用资金面、只用基本面与等权无显著差别。也就是说，股票特征本身的非线性组合没有帮助，结果靠的是宏观环境那一块。
- 信息系数（预测与下月收益的秩相关）各年均值在 −0.04 到 +0.09 之间，没有一年 t 值超过 2。
- 五因子 + 动量归因：相对等权的 alpha 年化 +3.7%（t = 1.23，不显著），显著负价值、负动量暴露。

## 结论

**未通过晋级。** 机器学习版本收益看起来最高（年化 14.6%，略高于 SPY 的 13.7%），但：波动比 SPY 高一半、夏普更低；
超额集中在 2020–2021，统计上区分不出运气；去掉宏观后反而显著变差。按预先登记的规则，不能把它用作选股依据，
也不能在看过结果后换模型或改参数再试（那是新研究、计入试验数）。

个股候选清单（configs/stocks.yml）的规则不变，仍只作“值得看一看”的参考。若以后再做，更有希望的方向是更长的历史
（更多宏观环境）和更多资金面数据（机构持仓、卖空），而不是更复杂的模型。

```
              --verification artifacts/ml/verification.json                                     # 需 lightgbm（pip install -e '.[ml]'）
usr-verify-ml --contract research/sp500-ml-rank/study.yml --panel artifacts/ml/panel.jsonl.gz --result artifacts/ml/result.json \
              --output artifacts/ml/verification.json
```
